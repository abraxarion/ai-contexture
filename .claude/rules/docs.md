# Docs

Applies to `docs/superpowers/**`.

- Name specs `YYYY-MM-DD-<topic>-design.md` and plans
  `YYYY-MM-DD-<topic>-implementation-plan.md`.
- The spec states intent; the plan states execution. When intent changes, change
  the spec first.
- Link a plan to its spec; do not restate spec content in the plan.
- Give each plan step a `- [ ]` checkbox, one file-touching action, and a command
  or observation that verifies it.
- List in each plan task the exact paths it creates or reads.
